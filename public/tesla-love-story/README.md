# Tesla Love Story Assets

This directory contains images for the Tesla Love Story page (`/a-tesla-love-story`).

## Required Images

Place the following images in this directory:

1. **tesla.jpg** (1000×511px)
   - Featured/hero image
   - Source: https://wp.aaronheine.com/wp-content/uploads/2019/10/tesla.jpg

2. **tesla-caraoke-comic.jpg** (1000×1263px approx)
   - Full comic strip with dialogue baked in
   - Source: https://wp.aaronheine.com/wp-content/uploads/2023/12/tesla-caraoke-comic.jpg

## Notes
